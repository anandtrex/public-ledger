  <p class="eyebrow">About this project</p>
  <h1>Evidence, with its working shown.</h1>
  <p>Public Ledger is a home for visualisations and material about the economy, society, and history.</p>
  <div class="about-note">
    <h2>How we work</h2>
    <p>Each project should identify its data source, date range, units, and important limitations. Analysis and estimates should be labelled clearly, and charts should include enough context to be understood without relying on color alone.</p>
  </div>
  <div class="about-note">
    <h2>How we use AI</h2>
    <p>This website has been developed with assistance from OpenAI Codex. AI has helped write the site’s code and explanatory text, find datasets, prepare data, and implement interactive charts and statistical calculations. The site’s author directs this work and makes decisions about the questions, measures, and presentation.</p>
    <p>The charts use published datasets from the sources credited on each page. Calculated values, such as absolute R&amp;D spending and fitted trends, are derived from those datasets using the methods described alongside the charts. AI-generated work can contain errors, so source links and methodological notes are provided to help readers assess the results.</p>
    <p>AI is used during development. The published site serves stored data and chart code locally, without calling an AI service when you visit.</p>
  </div>
